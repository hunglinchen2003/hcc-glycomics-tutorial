GlycoPOST GPST000584 的原始檔是 zip。解開後每個 MALDI 點是一個資料夾，例如 cohort_XZ_MALDI_raw/B19/0_B19/1/1SRef/。質譜本體是二進位 fid，采集參數在 acqu 與 acqus。

Raw files in GlycoPOST GPST000584 are zip archives. After extraction, each MALDI spot is a folder such as cohort_XZ_MALDI_raw/B19/0_B19/1/1SRef/. The spectrum itself is the binary fid; acquisition parameters are in acqu and acqus.

2. 由原始檔產生峰表2. Turn raw files into peak lists

在 flexAnalysis 4.0（build 14）對每張譜做下列處理，再把信噪比高於 3 的峰匯出成 xlsx。同一張 MALDI 板的點放在同一個活頁簿，每個點一張工作表。

In flexAnalysis 4.0 (build 14), process each spectrum as follows, then export peaks with signal-to-noise above 3 to xlsx. Spots from the same MALDI plate go in one workbook, one worksheet per spot.

  1. 基線扣除。Subtract the baseline.
  2. 重心化（centroid）。Centroid the spectrum.
  3. 用 SNAP 擷取單同位素峰，averagine 設為 sugar_na。這表示峰形用醣類、鈉加成離子來估。Pick monoisotopic peaks with SNAP and set averagine to sugar_na. The peak shape is modeled as a sodium-adducted glycan.
  4. 只保留 S/N > 3。Keep peaks with S/N > 3.
  5. 匯出 m/z、面積、強度與 S/N。後續定量用面積，不是強度。Export m/z, area, intensity, and S/N. Later quantification uses area, not intensity.

GD1 的成品已在 data\HCC-N-glycome\data\cohort_GD1\mass_list\。GD2 與徐州各是一個 mass_list.xlsx。

The finished GD1 workbooks are already in data\HCC-N-glycome\data\cohort_GD1\mass_list\. GD2 and Xuzhou each have one mass_list.xlsx.

3. 把峰對上聚醣3. Map peaks to glycans

GlyHunter 讀取 flexAnalysis 的 xlsx，先用每張譜裡一定會出現的強峰做線性質量校正，再把校正後的 m/z 比對聚醣組成資料庫。容差內若有多個候選，預設留下 ppm 最小的一個。

GlyHunter reads the flexAnalysis workbook, applies a linear mass calibration using strong peaks expected in every spectrum, then matches the calibrated m/z to a composition database. If several candidates fall inside the tolerance, the default is the one with the smallest ppm error.

主實驗要核對的設定Settings to check for the main experiment

論文方法寫明，校正用的五個 m/z 是 2271.837、1647.587、1967.71、1485.534、2417.895。電荷載體用 Na+。搜庫容差沿用 GlyHunter 設定檔的 mz_tol；本研究附帶的唾液酸異構體設定檔寫的是 50 ppm。開跑前用下面指令把設定抄出來檢查，不要只靠記憶。

The paper calibrates on m/z 2271.837, 1647.587, 1967.71, 1485.534, and 2417.895. The charge carrier is Na+. The search tolerance is whatever mz_tol is in the GlyHunter config; the linkage-specific config shipped with this study sets 50 ppm. Copy the config and read it before a run.

glyhunter config --copy .

glyhunter run "D:\Meta_analysis of glycomic data\data\HCC-N-glycome\data\cohort_GD1\mass_list\plate1.xlsx" -c .\config.yaml -o .\plate1_glyhunter

輸出資料夾裡，每張工作表一個 csv，另有三張總表：面積、強度、信噪比。串接樣本時用 summary_area.csv。聚醣欄是 Hex(5)HexNAc(4)NeuAc(2) 這類寫法，列名是譜圖名稱。

The output folder has one CSV per worksheet plus three summaries: area, intensity, and signal-to-noise. Use summary_area.csv to build the sample matrix. Glycans look like Hex(5)HexNAc(4)NeuAc(2), and the remaining columns are spectrum names.

唾液酸鍵結實驗是另一套化學。該設定檔把 NeuAc 加上 +13.03 與 +16.05 Da，校正峰也不同（2277.87、2271.83、1970.73、1647.59）。不要把那份 yaml 套到主隊列。
The linkage-specific experiment is a different chemistry. Its config adds +13.03 and +16.05 Da to NeuAc and uses different calibrants (2277.87, 2271.83, 1970.73, 1647.59). Do not reuse that YAML for the main cohorts.

自訂資料庫時，每一行寫 Hex(5)HexNAc(4)NeuAc(2) %。百分號後面的質量 GlyHunter 會自己重算，可以留空。血清聚醣的簡寫 H、N、F、S 分別是 Hex、HexNAc、dHex、NeuAc。

A custom database uses one line per composition: Hex(5)HexNAc(4)NeuAc(2) %. GlyHunter recalculates the mass after the percent sign. In the condensed serum notation, H, N, F, and S mean Hex, HexNAc, dHex, and NeuAc.

4. 從點位變成樣本 × 聚醣矩陣4. Build the sample-by-glycan matrix

GlyHunter 的欄名仍是板子上的點，例如含有 A1 的譜名。MALDI_positions.csv 把「第幾板、哪個點」接到樣本編號 S1、S2。plates.csv 再提供醫院原始編號，字首決定組別。

GlyHunter column names are still spot labels, such as a spectrum name containing A1. MALDI_positions.csv joins plate and spot to sample IDs such as S1. plates.csv carries the hospital ID, whose prefix determines the group.

library(tidyverse)

root <- "D:/Meta_analysis of glycomic data/data/HCC-N-glycome/data/cohort_GD1"
pos <- read_csv(file.path(root, "MALDI_positions.csv"), show_col_types = FALSE)
plates <- read_csv(file.path(root, "plates.csv"), show_col_types = FALSE)

# summary_area.csv is glycans x spectra. Adapt the regex to your sheet names.
area <- read_csv("plate1_glyhunter/summary_area.csv", show_col_types = FALSE)
long <- area |>
  pivot_longer(-glycan, names_to = "spectrum", values_to = "area") |>
  mutate(position = str_match(spectrum, "_([A-H](?:[1-9]|1\\d|2[0-4]))_")[, 2])

plate1 <- long |>
  inner_join(pos |> filter(plate == 1), by = "position") |>
  transmute(
    sample,
    glycan = glycan |>
      str_replace_all("Hex\\((\\d+)\\)", "H\\1") |>
      str_replace_all("HexNAc\\((\\d+)\\)", "N\\1") |>
      str_replace_all("dHex\\((\\d+)\\)", "F\\1") |>
      str_replace_all("NeuAc\\((\\d+)\\)", "S\\1"),
    area
  )

groups <- plates |>
  mutate(group = case_when(
    raw_sample == "QC" ~ "QC",
    str_starts(raw_sample, "H") ~ "HC",
    str_starts(raw_sample, "M") ~ "CHB",
    str_starts(raw_sample, "Y") ~ "LC",
    str_starts(raw_sample, "C") ~ "HCC"
  )) |>
  select(sample, raw_sample, group, plate)

write_csv(plate1, "plate1_long.csv")
write_csv(groups, "groups.csv")

八張板都做完後，用 complete(sample, glycan) 把沒抽到的組合補成 NA，再 pivot_wider。列是樣本，欄是聚醣。缺的峰是 NA，不是 0：0 會被後面的標準化當成真正量到的值。

After all eight plates, use complete(sample, glycan) so unobserved combinations become NA, then pivot_wider. Rows are samples and columns are glycans. A missing peak is NA, not 0. A zero would be treated as a real measured value during normalization.

5. 品管、填補、標準化、批次5. QC, imputation, normalization, batch

下面的規則與該研究分析腳本相同，並寫成可以獨立執行的函式。

The rules match that study’s analysis script and are rewritten here as functions you can run on their own.

  1. 只保留 chosen_samples.csv 裡的樣本。Keep samples listed in chosen_samples.csv.
  2. 去掉缺值比例 ≥ 50% 的樣本。該研究另外指定五個離群樣本：S231、S219、S243、S194、S212。Remove samples with at least 50% missing values. That study also removes five named outliers: S231, S219, S243, S194, S212.
  3. 在非 QC 樣本中，依組計算每個聚醣的檢出率。任一組檢出率 > 50% 就保留該聚醣。Among non-QC samples, compute each glycan’s detection rate inside each group. Keep a glycan if any group detects it in more than 50% of samples.
  4. 剩餘缺值填該樣本最小正值的一半。Fill remaining missing values with half of that sample’s minimum positive value.
  5. 中位數商數標準化：每個聚醣先取跨樣本中位數當參考，每個樣本再除以「觀測值 / 參考值」的中位數。Median-quotient normalization: each glycan’s cross-sample median is the reference, and each sample is divided by the median of its value-to-reference quotients.
  6. 取自然對數後，用 sva::ComBat 以板號為批次、疾病組為要保護的變項，參考批次設為第 1 板，再指數還原。Take the natural log, run sva::ComBat with plate as the batch and disease group protected, using plate 1 as the reference batch, then exponentiate back.
median_quotient_norm <- function(mat) {
  ref <- apply(mat, 2, median, na.rm = TRUE)
  quot <- sweep(mat, 2, ref, "/")
  factors <- apply(quot, 1, median, na.rm = TRUE)
  sweep(mat, 1, factors, "/")
}
ComBat 用自然對數；後面的檢定用 log2。兩次對數不要疊加。批次校正前要先有組別標籤，否則它會把疾病差異一起消掉。
ComBat uses the natural log. The later tests use log2. Do not stack the two logs. Batch correction needs the group label, or it will also remove disease differences.

6. 衍生特徵（可選）6. Derived traits (optional)

單一組成很難對應生化路徑。衍生特徵把許多聚醣收成少數指標，例如分枝程度、核心岩藻糖化、半乳糖化、平分型 GlcNAc、唾液酸化。該論文用 GlyTrait 計算；GlyTrait 已由作者標成停用，現用的後續工具是 glydet。結構字串在 human_serum_glycans.csv 的 GlycoCT 欄。

A single composition is a weak proxy for a pathway. Derived traits collapse many glycans into a few indices: branching, core fucosylation, galactosylation, bisecting GlcNAc, and sialylation. The paper calculated them with GlyTrait. Its authors now mark GlyTrait as deprecated; the successor is glydet. GlycoCT strings are in human_serum_glycans.csv.

教學上可以先手算一個透明的例子，確認方向再交給 glydet：

In class, calculate one transparent example before handing the table to glydet:

# Proportion of fucosylated glycans in one sample.
# abundance is a named numeric vector of compositions such as H5N4F1S1.
fucosylation <- function(abundance) {
  fuc <- abundance[str_detect(names(abundance), "F[1-9]")]
  sum(fuc, na.rm = TRUE) / sum(abundance, na.rm = TRUE)
}

7. 統計分析7. Statistical analysis

輸入是校正後的面積寬表，加上 groups 與 clinical.csv。臨床欄有年齡、性別、AST、ALT、GGT、ALB、TBIL、TP、AFP、Child-Pugh 與 TNM。QC 在模型前拿掉。

The input is the corrected wide area table, plus groups and clinical.csv. Clinical columns include age, sex, AST, ALT, GGT, ALB, TBIL, TP, AFP, Child-Pugh, and TNM. Remove QC before modeling.

論文使用的分組模型The study’s group model

每個聚醣分別做 ANCOVA：log2(面積) ~ 年齡 * 性別 + 組別。組別順序是 HC、CHB、LC、HCC。用 White 校正處理變異數不齊，偏 eta 平方當效果量。全部聚醣的組別 p 值再用 Benjamini–Hochberg 校正。事後比較沿用同一條公式，只在組別之間兩兩看。

Each glycan gets its own ANCOVA: log2(area) ~ age * sex + group. Group order is HC, CHB, LC, HCC. White’s adjustment handles unequal variance, and partial eta squared is the effect size. Benjamini–Hochberg is applied across glycans. Post-hoc tests use the same formula and compare groups pairwise.

library(rstatix)
one <- ancova_long |>
  filter(glycan == "H5N4F1S1") |>
  anova_test(log2_area ~ age * sex + group, white.adjust = TRUE, effect.size = "pes")
# Repeat by glycan with group_by(glycan), then adjust_pvalue(method = "BH").

若要問「這些差異是不是只反映肝功能變差」，把 ALBI、TP、TBIL、GGT、AST、ALT、ALB 與 AST/ALT 比加進協變量。這是敏感度分析，不是第一張圖該用的模型。

To ask whether the differences only reflect worsening liver function, add ALBI, TP, TBIL, GGT, AST, ALT, ALB, and the AST/ALT ratio as covariates. That is a sensitivity analysis, not the model for the first figure.

和 AFP 放在同一個問題裡Put AFP in the same question

HCC 對非 HCC 可以用聚醣矩陣做邏輯斯迴歸或正規化迴歸，再用同一批留出的樣本畫 ROC，和 AFP 的 ROC 比較。外部隊列 GD2、XZ 只能用來測試，不能再調參數。教程腳本把這一步留成最後一段，並把資料切成訓練與測試，避免用同一筆資料既選變項又報準確率。

For HCC versus the other groups, a logistic or penalized regression on the glycan matrix can be scored by ROC on held-out samples and compared with AFP. GD2 and XZ are test sets only; do not retune on them. The script below keeps this as the last block and splits train from test so variable selection and the reported accuracy are not the same rows.

drop_samples <- dat |>
  summarise(na_prop = mean(is.na(area)), .by = sample) |>
  filter(na_prop >= 0.5) |>
  pull(sample)
drop_samples <- union(drop_samples, c("S231", "S219", "S243", "S194", "S212"))

dat <- dat |> filter(!sample %in% drop_samples)

keep_glycans <- dat |>
  inner_join(groups, by = "sample") |>
  filter(group != "QC") |>
  summarise(detect = mean(!is.na(area)), .by = c(glycan, group)) |>
  filter(detect > 0.5) |>
  distinct(glycan) |>
  pull(glycan)

dat <- dat |>
  filter(glycan %in% keep_glycans) |>
  group_by(sample) |>
  mutate(area = if_else(is.na(area), min(area, na.rm = TRUE) / 2, area)) |>
  ungroup()

wide <- dat |> pivot_wider(names_from = glycan, values_from = area)
mat <- as.matrix(wide[, -1, drop = FALSE])
rownames(mat) <- wide$sample
norm <- sweep(mat, 1, apply(sweep(mat, 2, apply(mat, 2, median), "/"), 1, median), "/")

meta <- groups |>
  filter(sample %in% rownames(norm), group != "QC") |>
  inner_join(clinical, by = "raw_sample") |>
  distinct(sample, .keep_all = TRUE)

log_mat <- log2(norm[meta$sample, , drop = FALSE])
pca <- prcomp(log_mat, center = TRUE, scale. = TRUE)
plot(pca$x[, 1:2], col = as.integer(factor(meta$group)), pch = 19)

ancova_long <- as_tibble(log_mat, rownames = "sample") |>
  pivot_longer(-sample, names_to = "glycan", values_to = "log2_area") |>
  inner_join(meta |> select(sample, group, age, sex), by = "sample") |>
  mutate(group = factor(group, levels = c("HC", "CHB", "LC", "HCC")))

ancova_long |>
  filter(glycan == names(sort(apply(log_mat, 2, var), decreasing = TRUE))[1]) |>
  anova_test(log2_area ~ age * sex + group, white.adjust = TRUE, effect.size = "pes")
clinical.csv 的第一欄是醫院原始編號 raw_sample，不是 S1 這種專案編號。若合併後列數暴增，代表一筆臨床資料配到多個點，先用 distinct 檢查鍵。
The first column of clinical.csv is the hospital ID raw_sample, not the project ID such as S1. If the join multiplies rows, one clinical record matched several spots; check the key with distinct.
