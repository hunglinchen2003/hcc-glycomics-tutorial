# HCC serum N-glycomics tutorial

Standalone bilingual (繁體中文 / English) lesson: Bruker MALDI raw files, flexAnalysis peak lists, GlyHunter annotation, sample-by-glycan matrix, normalization, and statistics.

Open `index.html` locally, or the published page once GitHub Pages is enabled:

https://hunglinchen2003.github.io/hcc-glycomics-tutorial/

The workflow follows Fu et al., Nature Communications (2026), https://doi.org/10.1038/s41467-026-68579-x. Raw data: GlycoPOST GPST000584. This repository is an independent teaching page and does not redistribute the spectra.
